Project Overview

NGXS Ticket Desk

A modern, single-page Ticket Management application designed to demonstrate state-of-the-art Angular principles, state management with NGXS, and robust unit testing.

Technical Architecture

Angular 21+

Standalone Components & Signals

Built using modern standalone components and dependency injection APIs. Utilizes the high-performance Angular Signals architecture for template reactivity.

NGXS State Management

Unidirectional State Flow

Manages application state centrally using NGXS actions, selectors, and state handlers. Employs selectors integrated with signals (`selectSignal`) for real-time reactivity.

Tailwind CSS v4

Modern Utility Styling

Styled completely with Tailwind CSS utility classes, achieving a polished look with HSL tailored color schemes, glassmorphic card effects, and clean typography.

Vitest Unit Testing

Robust Quality Assurance

Includes an extensive unit testing suite covering services, interceptors, central stores, and component user interactions for 100% feature coverage and reliable builds.

Key Capabilities

  • Interactive Ticket Desk:

    Add, status-update, and delete tickets directly from the dashboard UI.

  • Real-time Filtering:

    Filter tickets by status (All, Open, In Progress, Closed) instantaneously.

  • Mock API & Interceptor:

    Uses a memory-backed HTTP interceptor simulating an online REST API.

  • Toast Notification Alerts:

    Visual notification feed for every system action, improving UX.
